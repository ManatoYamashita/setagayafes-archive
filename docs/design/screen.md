## JS を使わない動き

### MENU: `popover` と `popovertarget`

- `<button popovertarget="site-menu">` と `<nav id="site-menu" popover>` だけで開閉する
- Escape・外側のクリックで閉じ、閉じるとフォーカスはボタンへ戻る（ブラウザが行う）
- パネルは画面内に収まる高さに制限し、内容が長いときはパネル内を縦にスクロールする。E2E では幅320px・高さ256pxで、Tab で「閉じる」まで移動して操作できることを確かめる
- `command` / `commandfor`（Invoker Commands）は使わない。古いブラウザ向けの polyfill が JS になるため

### ヒーロー

- 2026-11-10 にオーナーと決めた（Issue #30）。最新5回の切り替え（radio と `:has()`）は外し、最新回の写真1枚だけにした。全回は下の一覧にある
- 見出しは `UI` の `heroTitle`（日本語「東京都市大学世田谷祭／アーカイブ」、英語「Setagaya Festival／Archive」）。`<title>` と OGP はこれまでどおり `siteName`
- 説明文の回・年・回数は、データ（`FESTIVALS`）から導く。年次の追加で書き換える文言は無い
- 参考にあったバッジ（見出しの上と枠の左上）は、2026-11-11 のオーナーの指示で外した
- 「過去の回を見る」はページ内の `#archive` へ飛ぶ。英語版でも `hreflang` を付けない（e2e は `href^="#"` を除いて検査する）

### 初期表示: ヒーローの入場（`@keyframes`）

- 2026-11-14 にオーナーと決めた（Issue #34）。ヒーローだけを、読む順（見出しの1行目 → 2行目 → 説明 → ボタン）に 50ms ずつずらして、下から 0.75rem 立ち上げる。600ms
  - ヘッダーと一覧は動かさない。ヘッダーは視線の起点、一覧は読む・選ぶ対象のため
- 動かすのは `transform` と `opacity` だけ。CSS アニメーションはコンポジタで動くため、画像の読み込み中でもコマが落ちない
- 曲線は `@theme` の `--ease-out`（`cubic-bezier(0.23, 1, 0.32, 1)`）。Tailwind の既定の ease-out は弱く、動きが尾を引くため上書きした
- **枠の写真は遅らせない。** 最初から、800ms かけて浮かび上がらせる。写真は LCP の要素なので、遅延を付けると、その分だけ見え始めが遅れる
- 不透明度 0 のときに描かれた要素は、Chromium の LCP の候補にならない。どの要素が LCP になるかは、写真がいつ届くかで変わる
  - 写真がアニメーションの最初のコマより先に届く（手元の速い回線）: 写真は不透明度 0 で描かれ、候補から外れる。Playwright の Chromium で、LCP の要素は `A.outline-button`（412px）・`P.org`（1280px）に変わった。値は main と同じ 48〜64ms
  - 写真がアニメーションの始まった後に届く（遅い回線）: 写真は不透明度が 0 より大きい状態で描かれ、そのまま LCP になる。本番の Lighthouse 13.5.0（モバイル、2026-11-14）では、日英とも LCP の要素は写真で、LCP は 1.4〜1.5 秒（刷新前の記録 1.4 秒と同じ）。4カテゴリとも 100、CLS 0
  - どちらの場合も、写真は届いた次のコマから見え始めるので、訪問者から見た遅れは無い
- `prefers-reduced-motion: reduce` では移動をやめ、同じ時間の不透明度だけにする
- 動きの確かめ方: DevTools の Animations パネルで再生速度を 10% にする（CDP なら `Animation.setPlaybackRate`）

### プレビュー: `popover` と、sandbox を付けた iframe

- 2026-11-11 にオーナーと決めた（Issue #30）。カードとヒーローの写真の「プレビュー」で、その回のサイトを、このページの上の大きなパネルで開く
- `<button popovertarget="preview-97">` と `<div id="preview-97" popover role="dialog">` で開閉する。JS は使わない。Esc・外側のクリック・「閉じる」で閉じる
  - `<dialog>` をモーダルで開くには JS か `commandfor` が要る。どちらも使えない（規約 §1）。popover は背景を操作不可にしないが、`::backdrop` で暗くする
- iframe は `loading="lazy"`。閉じている popover は `display: none` なので、開くまで取得されない（Chromium で実測。転送量の予算は変わらない）。Firefox・Safari では確かめていない
- iframe には `sandbox="allow-scripts allow-popups allow-popups-to-escape-sandbox"` を付ける。`allow-same-origin` は付けない
  - 過去回のサイトは同じホストにあり、古い JS が動く。同じオリジンのまま埋めると、その JS が新トップを書き換えられる。sandbox で別のオリジンとして扱わせ、`script-src 'none'` の守りを保つ
  - 代わりに、Cookie や localStorage を使う仕掛けは、プレビューの中では動かないことがある。「サイトを見る」で開けば当時のとおりに動く
- CSP に `frame-src 'self'` を足した。過去回のサイトは、同じホストからの iframe を許している（第97回は `X-Frame-Options: SAMEORIGIN`、他の回はヘッダ無し。2026-11-11 に確かめた）
- 外部にある回（第87回、Wayback Machine）は `frame-src 'self'` の外なので、プレビューを出さない（`src/lib/preview.ts` の `hasPreview()`）
- 開いている間は、後ろのページをスクロールさせない（2026-11-11 のオーナーの指示）。`html:has(.preview:popover-open) { overflow: hidden }` で止める。JS は使わない
  - ホイールとタッチのスクロールは、iframe の中のサイトにだけ効く。サイトの端まで行っても後ろへ伝わらない（`overscroll-behavior: contain`）
  - スクロールバーが消えて横にずれないよう、開いている間だけ `html` に `scrollbar-gutter: stable` を付ける
    - 常に付けると、スクロールバーが常に出る環境（CI の Linux）で、`scrollWidth - clientWidth` が -15 になった。スクロールバーの幅を二重に取っている恐れがあるので、開いている間に限った
  - e2e は、パネルの帯の上でホイールを回してもページが動かず、閉じれば動くことを見る
- 写真の上の膜は、膜そのものはクリックを通し（`pointer-events: none`）、ボタンだけが受ける。膜の外はカード全体のリンク（見出しのリンクを `::after` で伸ばしたもの）のまま
- 膜は `position: relative`・`z-index: 1` で写真の上に置く。写真の箱（`Capture.astro`）が位置指定されているので、指定しないと写真の下に描かれる

### 絞り込み: radio と `:has()`

- `name="era"` の radio を3つ置き、`.archive:has(#era-musashi:checked)` で他の時代のカードを `display: none` にする
- radio は `sr-only` で隠し、`label` を丸枠のピルとして描く。矢印キーでの移動はブラウザの radio のまま
- 表示中の件数（「5件を表示中」）も、同じ `:has()` で出し分ける

### グリッドの組み方

- カードはすべて同じ大きさにする。3列（64rem 以上）・2列（40rem 以上）・1列
  - 以前の大小の組み（`:nth-child(An+B of S)` で6件ごとに大きなカードを置く）は、Issue #30 で撤去した
- 一覧はヒーローの最新回も含めた全回を並べる。時代で絞り込んでも、最新の回が消えないようにするため
- カードの高さは行ごとに揃え、タグをカードの下端に寄せる（`margin-block-start: auto`）
- 洗いの帯は `.archive::before` で描く。画面の左端から幅の約8割まで。`.archive` に `isolation: isolate` を付け、`z-index: -1` の帯が `body` の背景の下に潜らないようにする

## 英語版（`/en/`）

- 日英は同じ部品で組み、`lang` を渡して文言だけを替える
  - ページの文言は `src/i18n/ui.ts` の `UI` に置く。各回の事実（テーマ・祭の名称・時代・状態）は `src/data/` の日英を使う
  - 両言語のキーが揃っていることは `scripts/i18n.test.mjs` で確かめる
- **テーマは原文を題名に残し、英訳を下に添える**（Issue #1 の決定）。`headingOf()` が決める
  - 原文には `lang="ja"` を付ける。読み上げと、日本語の字形の選択のため
  - 元から英字のテーマ（`COSMOS` など）は1回だけ出す。テーマが不明な回は英語の祭の名称
- 回は日本語で「第97回」、英語で序数「97th」（`roundLabel()`）
- 英語版から各回のサイト・関連サイトへのリンクには `hreflang="ja"` を付ける。リンク先は日本語のため
- 言語切替は MENU とフッターの最後の項目。リンクの文字は切り替え先の言語で書き（「English」「日本語」）、`lang`・`hreflang` を付ける
- `<head>` に `rel="alternate"` の `hreflang`（`ja`・`en`・`x-default`）を出す。`x-default` は `/`
- 日付の書式（`2026.10.31–11.01`）は両言語で同じ

**検査:** e2e は同じテストを `/` と `/en/` の両方で流す。加えて、`/en/` で `lang="ja"` の外に日本語の文字（ひらがな・カタカナ・漢字）が無いこと、
`aria-label`・`alt`・`meta` の値にも無いことを確かめる。訳し忘れと `lang` の付け忘れを、どちらも落とす。

## 写真

- サムネイルは 2560x1600（16:10）の画面写真。枠もすべて 16:10 にして、写真を切らずに見せる
  - 縦長（4:5）に切ると、横長の画面写真の中央の帯しか残らない（ロゴもナビも消える）
- 原画像は `src/lib/captures.ts` の `captureOf()` で引き、`CAPTURE_IMAGE_PROPS`（AVIF・上端基準で切り出し）で `<Image>` に渡す。撮影の手順は [capture.md](../ops/capture.md)
- `widths` と `sizes` はグリッドでの実際の幅から決める（`Archive.astro` の `SIZES`）
  - 遅延読み込みの写真は `sizes` の先頭に `auto` を付ける（`Capture.astro`）。表示中の幅で画像を選ばせるため。`Archive.astro` の `SIZES` は、`auto` に対応しないブラウザ向けの控え
  - ヒーローの写真（`loading="eager"`）には `auto` を付けない。仕様上、遅延読み込みでない画像では `auto` は無視される
  - カードの画像候補は最大1280px。均等な列のカードは、2列の640pxでも DPR 2 で足りる
  - 1080px の候補も置く。1列のカード（390px の画面で358px）を DPR 3 で見る端末が、1280px を取らずに済む（全体の転送量が 991KB から 850KB に減った）
- 撮影前の回（`hasCapture()` が false）は、回の数字を大きく組んだ代替表示にする。年次の追加でデータだけ先に入れても、ビルドは落ちない
- ヒーローの写真だけ `loading="eager"`・`fetchpriority="high"`。カードはすべて `loading="lazy"`

## はまりどころ

- **1列のグリッドでも `grid-template-columns: minmax(0, 1fr)` を書く。** 書かないと列の幅が中身の最小幅に引きずられ、
  320px で大きな見出しが画面からはみ出した（e2e の横スクロール検査で発見）
- **大きな見出しには `overflow-wrap: anywhere` を付ける。** `word-break: auto-phrase` は「カラクリ」のような1語を分けないため
- **日本語の文章をソース上で改行しない。** 改行は空白として描かれる（「残しています、 各回」のようになる）
- **12px 未満の文字を使わない。** Lighthouse の「読みやすい文字サイズ」で減点される
- **日英で文の区切りが違う。** 2つの文を続けるとき、日本語は間を空けず、英語は空白を入れる。文言は文ごとに分けず、`UI` の1つの値に続けて書く
- **写真の上の白い文字は、描画結果で 4.5:1 を測る。** トークンからは計算できない。関連サイトのタイルは、320px と 1280px の両方で最悪値を測った（Issue #30 のレビュー。暗いグラデーションを強めて 6:1 以上にした）
- **radio＋`:has()` の選択状態には `forced-colors` の規則を付ける。** 強制カラーでは背景色が消え、どれを選んだか分からなくなる。`SelectedItem`・`SelectedItemText` で描く（e2e で検査する）
- **日本語の短い文にも `word-break: auto-phrase` を付ける。** 見出し以外（タイルの名前・フッターの注記）でも、「旧サ／イト」のように語の途中で折れる
- **`:hover` は `@media (hover: hover)` の中に書く。** タッチ端末では、戻ったときに hover の見た目が残る
- **favicon を置く。** 無いと `/favicon.ico` が 404 になり、Lighthouse の Best Practices がコンソールのエラーで減点される
