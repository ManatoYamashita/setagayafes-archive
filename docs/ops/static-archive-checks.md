# 静的化後の公開ページを確認する

旧 WordPress を静的化したときに、画面とリンクの回帰を確認する。等々力祭 2011・2012 の対応経緯は [Issue #2](https://github.com/ManatoYamashita/setagayafes-archive/issues/2) を参照。

1. 変更前の HTML と主要画面の撮影を公開フォルダの外に控える。修正前に配信中の HTML と作業元が一致するか確かめる。
2. 静的版で使えなくなった検索、RSS 購読、コメント投稿を点検する。検索欄があるときは、語句を送った URL の応答本文を通常のページと比べる。どちらも 200 でも本文が同じなら検索結果は出ていない。受付を終えた操作は欄やボタンごと外し、記事・既存コメント・企画一覧への導線を残す。
3. 旧ドメインの画像参照を、本文の画像に加え、バナー、背景、サムネイル、拡大画像のリンクでも探す。アーカイブ内に対応する実体を確認してから参照を書き換える。
4. 配信後は変更前と同じ公開 URL で、更新したページが 200 で修正後の本文を返すことを確かめる。差し替えた画像は 200 かつ画像の Content-Type であることを確認し、代表ページで画像の表示とナビゲーションをブラウザーでも確認する。
5. 旧管理入口へのアクセスが拒否されることを確認する。投稿フォームの確認には公開サイトへの送信を使わない。

画面の撮影比較、リンクと画像の HTTP 検査、サーバー側の実行設定の確認はそれぞれ記録する。公開 URL の応答から確認できるのは、その URL の配信状況まで。
