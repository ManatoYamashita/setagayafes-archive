# festivals データ

トップページに載せる各回と関連サイトのデータの、項目の意味・出典・導出の規則。

- 各回: `src/data/festivals.ts`
- 関連サイト: `src/data/related-sites.ts`
- テスト: `scripts/festivals.test.mjs`（`pnpm test`）

## 出典

- **正本は Issue #1 の表**（開催日・キャンパステーマ・状態）。テーマは各回のサイトに書かれた原文のまま
- リンク先のフォルダ名は、サーバーの公開フォルダの一覧（`ls ~/www/archive`）と、HTTP で 200 が返ることで確かめた（2026-11-06）
- 第4回 等々力祭の開催日は、当時のサイトの記載「平成24年11月24日(土)～25日(日)」から拾った
- 委員会の旧サイトの年は、そのサイトの更新履歴（2011年まで）による

## データに持つもの

各回で変わる事実だけを持つ。

| 項目                        | 内容                                                                                                            |
| --------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `round`                     | 回                                                                                                              |
| `dates.start` / `dates.end` | 開催日の初日と最終日（ISO 8601）                                                                                |
| `dates.estimated`           | 推定の日付であることを示す印。第75回だけ                                                                        |
| `theme`                     | キャンパステーマ。`ja` は原文、`en` は英訳。元から英字のテーマは `ja` と `en` が同じ。不明なら `null`（第75回） |
| `commonTheme`               | 学園祭の共通テーマ（日本語だけ）。記録として持つ。カードには載せない                                            |
| `status`                    | `held`（通常）・`online`（オンラインのみ）・`hybrid`（対面＋オンライン）・`cancelled`（中止）                   |
| `statusReason`              | 中止の理由（日英）。中止の回だけに持つ                                                                          |
| `externalLink`              | このホストにフォルダが無い回のリンク先。今は第87回の Wayback だけ                                               |

## 関数で導くもの

規則が決まっているものは、データに持たず関数で導く。年次の追加で書き間違えないため。

| 関数                      | 規則                                                                                      |
| ------------------------- | ----------------------------------------------------------------------------------------- |
| `yearOf(round)`           | 回＋1929                                                                                  |
| `eraOf(round)`            | 79回までは `musashi`（武蔵工業大学）、80回からは `tcu`（東京都市大学）。2009-04-01 に改称 |
| `festivalNameOf(round)`   | MI-TECH祭（75〜79回）→ TCU祭（80〜81回）→ TCU世田谷祭（82回）→ 世田谷祭（83回〜）         |
| `pathOf(round)`           | `/<回><序数>/`。例: `/81st/`・`/82nd/`・`/83rd/`・`/97th/`                                |
| `linkOf(festival)`        | `externalLink` があればその URL、無ければ `pathOf`                                        |
| `titleOf(festival, lang)` | カードの見出し。テーマ、テーマが不明なら祭の名称                                          |
| `latestFestival()`        | 回が最大のもの。ヒーローに出す                                                            |

- 英訳は Claude が作り、オーナーが確認する

## 状態のタグ

`STATUS_LABELS` が持つ。`held` はタグを付けない。

| `status`    | 日本語           | 英語               |
| ----------- | ---------------- | ------------------ |
| `online`    | オンライン開催   | Online             |
| `hybrid`    | 対面＋オンライン | In person + online |
| `cancelled` | 中止             | Cancelled          |

## 関連サイト

| 項目             | 内容                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------- |
| `id`             | 識別子                                                                                        |
| `name`           | 名称（日英）                                                                                  |
| `dates` / `year` | 祭のサイトなら開催日、そうでなければ年                                                        |
| `path`           | このホストのフォルダ                                                                          |
| `blockedBy`      | リンクを張る前に閉じる必要がある Issue の番号。閉じるまでは、名前だけを載せてリンクを張らない |

等々力祭の2件は、WordPress のまま動いている。静的化（Issue #2）が終わるまでリンクしない。
